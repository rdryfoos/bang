# SURFACE.md: Bang

What Bang and the machinery around it expose on the machine that runs it, and how each control holds. Written for someone deciding whether to run this on a computer they are responsible for.

How to read a row. **Control** is what stops the thing. **Holds by** says what kind of stop it is: *construction* means the layout makes the bad case impossible; *script* means a program refuses it and can be edited or skipped; *record* means it is written down afterwards and nobody independent checked it; *instruction* means an agent was told not to and nothing enforces it. **Bypass** lists every way known to get past the control; a blank cell would be a claim, so none is blank. **Verify** is a command or a look that shows the control is in place on this machine today. Observed and not declared here is a defect in this file.

Written 2026-09-19 at the project's birth. Rewritten 2026-10-05 after two cold Linux runs and the SpecAssay 0.5.5 hotfix.

## Words used here

- **Card**: one unit of work on the board, with a branch of its own (`potato/BAN-1`).
- **Worktree**: the card's own checkout of this repository, cut from `main`, where its worker runs.
- **Cannon**: the board and daemon (a fork of Potato Cannon) that starts a worker when a card moves and keeps the record.
- **Worker**: a Claude Code session the Cannon starts for one card and one column (Spec, Build).
- **Buddy**: one more agent a person can talk to from a card; it reads the whole project and, in Review only, may edit the card's branch.
- **Gate**: `scripts/gate.sh`, the checks a branch must pass (tests, governed files unchanged, the SpecAssay traceability check writing its manifest) before Review and again at promotion.
- **Promotion**: the only intended way onto `main`: the Cannon merges a card's branch when a hand drags it from Review to Done, and the Gate passes on the merge.
- **Hook**: a git pre-commit script in `scripts/`, switched on by `git config core.hooksPath scripts` at BANG.md step 7. Runs only in a clone that has done that step; a commit made elsewhere never meets it.
- **Governed file**: `PRD.md`, `CASE.md`, `CONSTITUTION.md`, `SURFACE.md`, `design/`, `scripts/`, the SpecAssay scripts and the workflows. A card's branch may not change them; the Gate refuses if it does.
- **CASE**: the reader's own answers about what they are building, kept in a file outside the repository.
- **Receipt**: the line the Gate writes into the project journal when it passes on `main`.

## Local controls {#local}

| Row | What | Control | Holds by | Bypass | Verify |

| LC1 | The reader's answers | The filled CASE lives at `BANG_CASE_FILE`, outside the worktree, where no git command run inside this repository can reach it. A second control, `scripts/no-private-answers.py`, refuses a commit that carries a value out of the answers. | Construction for the location. Script (a hook) for the commit check. | Row | What | Bound | Holds by | Bypass | Verify |
|-----|------|-------|----------|--------|--------|

## What this file does not claim

- No control here survives root on the machine, or the operator's own hand with `--no-verify` or `BANG_PROMOTION=1`. The hooks are discipline made visible, not walls.
- No second party has attested anything on a machine with `RECEIPT_SOURCE="local"`.
- The Cannon daemon has no authentication; the loopback bind is the whole of its access control.
- Claude Code's own permission classifier refuses some BANG.md steps (observed: steps 5, 7 and 10 on 2026-10-02) and the person runs those lines by hand; which steps it refuses varies between runs, so a refusal is not a control this file relies on.
